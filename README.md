# DOTVOZ Terminal for Mac — releases

Signed, notarized builds of the native Mac app and the Sparkle appcast that
points at them. Binaries only; the source lives elsewhere.

Each GitHub Release here is one build (`CFBundleVersion`), published by the
release job. The app checks
`https://github.com/devjah/dotvoz-terminal-mac-releases/releases/latest/download/appcast.xml`
for updates.
